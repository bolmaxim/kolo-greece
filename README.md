# Kolo: Greece

Мобильная 2.5D puzzle-platformer игра о живом хлебном круге Kolo, который путешествует по Греции.

## Игровая формула

Игрок катится, прыгает, делает подкат и использует свойства теста, чтобы решать короткие физические головоломки. Основной вид — сбоку; отдельные уровни заканчиваются короткими динамичными участками с камерой за спиной.

## MVP

- 20–25 коротких уровней
- 3 главы: Метеоры, Корфу, Санторини
- 3 состояния Kolo: липкий, тяжёлый, твёрдый
- движение влево/вправо, прыжок, подкат и контекстное взаимодействие
- один головоломочный мини-босс
- карта путешествия
- три необязательные задачи на уровень
- подсказки за rewarded video
- одна косметическая коллекция

## Визуальное направление

Фоны и дальние планы Метеор стремятся к реалистичной подаче: узнаваемая геология, монастыри, естественное освещение, облака и атмосферная перспектива. Kolo и игровые механизмы остаются более выразительными и контрастными, чтобы управление и головоломки хорошо читались на телефоне.

## Unity-проект

- Редактор: Unity `6000.0.44f1`.
- Пакеты: Universal Render Pipeline, Input System и Unity Test Framework.
- Откройте корень репозитория через Unity Hub.
- При первом открытии дождитесь восстановления пакетов.
- Откройте `Assets/Scenes/Bootstrap.unity` и нажмите Play. Bootstrap автоматически загрузит `MeteoraSlice`.
- Сгенерированные папки `Library`, `Temp`, `Logs`, `Obj` и пользовательские настройки не добавляются в Git.
